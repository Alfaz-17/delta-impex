# Delta Impex

Global provider of high-quality marine engine spare parts and advanced RO water treatment solutions.

## Tech Stack
- **Framework**: Next.js 14 (App Router)
- **Styling**: Tailwind CSS / CSS Variables
- **Animations**: Framer Motion
- **Icons**: Lucide React

## Getting Started
1. Install dependencies: `npm install`
2. Run development server: `npm run dev`
3. Build for production: `npm run build`

## Project Structure
- `/app`: Application routes and layout
- `/components`: Reusable UI components
- `/components/sections`: Page-specific sections (Hero, Technology, etc.)
- `/public`: Static assets and image frames

## Deployment
This application is optimized for deployment on **Vercel**.
